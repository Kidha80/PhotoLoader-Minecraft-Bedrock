📷 Photo Loader для Minecraft Bedrock

Выбери фото из галереи — получи готовый аддон .mcaddon со своими фотографиями в полном качестве.
Как установить
  1. Скачанный файл PhotoLoader.mcaddon открой в Minecraft (нажми на файл в загрузках).
  2. В настройках мира включи оба пака (поведение + ресурсы).
  3. В игре скрафти Фоторамку (8 бумаги + стеклянная панель) или /give @s photo:placer.
  4. Нажми Фоторамкой по стене/полу/потолку — выбери фото и размер. Клик по центру фото — настройка/удаление.
  5. Чтобы добавить новые фото — собери аддон заново с полным списком и открой файл снова: пак обновится.
