# 📷 Photo Loader — свои фото в Minecraft Bedrock

Аддон для Minecraft Bedrock Edition, который позволяет разместить **любые фотографии из галереи** в мире — не пиксель-арт из блоков и не замена текстур картин, а полноценные фото-поверхности:

- 🖼️ Фото в **полном разрешении** (до 4096px) — без потери качества, с сохранением пропорций;
- 📐 Любой размер — от 0.5 до 16 блоков, меняется прямо в игре;
- 🧱 Размещение на **стенах, полу и потолке**, с двух сторон видно без зеркалирования;
- ✨ Опция свечения — фото видно в темноте;
- 🛠️ Настройка и удаление в игре через удобное меню (без команд);
- 📦 Никаких экспериментальных функций — стабильный Script API (Minecraft 1.21+).

> **Как это устроено.** Bedrock не позволяет аддону читать галерею телефона прямо во время игры (текстуры грузятся только из ресурс-пака). Поэтому в комплекте идёт **генератор**: он берёт ваши фото из галереи и за секунды упаковывает их в готовый `.mcaddon`. Добавить новые фото = пересобрать файл и открыть его снова — пак обновится, все уже размещённые фото останутся на местах.

## 🚀 Быстрый старт (телефон)

1. Скачайте файл [`generator.html`](generator.html) из этого репозитория и откройте его в браузере (Chrome/Safari).
2. Нажмите **«Выбрать фото из галереи»**, добавьте любые фотографии, при желании переименуйте.
3. Нажмите **«Собрать PhotoLoader.mcaddon»** — файл скачается.
4. Откройте скачанный `PhotoLoader.mcaddon` — Minecraft импортирует оба пака автоматически.
5. В настройках мира включите паки **Photo Loader BP** и **Photo Loader RP**.

Всё происходит в браузере на вашем устройстве — фото никуда не загружаются.

## 💻 Быстрый старт (ПК)

```bash
pip install pillow
python3 tools/add_photos.py мое_фото.jpg отпуск.png
# → dist/PhotoLoader.mcaddon — откройте двойным кликом
```

Полезные команды:

```bash
python3 tools/add_photos.py --name "Наша дача" дача.jpg   # своё имя фото
python3 tools/add_photos.py --max 4096 фото.jpg           # максимум качества
python3 tools/add_photos.py --list                        # список фото
python3 tools/add_photos.py --remove 2                    # удалить фото с id 2
python3 tools/add_photos.py --build-only                  # просто пересобрать
```

## 🎮 Как пользоваться в игре

| Действие | Как |
|---|---|
| Получить Фоторамку | скрафтить (8 бумаги + стеклянная панель по центру) или `/give @s photo:placer` |
| Разместить фото | нажать Фоторамкой по любой поверхности — ставится сразу |
| Выбрать другое фото / размер | **присесть** и нажать Фоторамкой по поверхности — откроется меню |
| Настроить или удалить фото | нажать рукой по центру размещённого фото |

В меню: выбор изображения, размер (длина большей стороны в блоках) и свечение. Обычный клик ставит фото с последними настройками — удобно оклеивать стены сериями. При входе в мир в чат приходит строка `[Photo Loader] v… активен` — по ней видно, что скрипты работают.

> **Обновляете аддон?** Minecraft хранит старые версии паков. Перед импортом нового `.mcaddon` удалите старые: Настройки → Хранилище → Наборы поведения / Наборы ресурсов → Photo Loader → удалить, затем откройте новый файл и заново включите паки в мире.

## 📁 Структура репозитория

```
addon/
  behavior_pack/   — логика: предмет, сущность фото, скрипты (Script API)
  resource_pack/   — рендер: геометрия, текстуры фото, меню
  photos.json      — реестр добавленных фото
tools/
  add_photos.py    — генератор для ПК (добавляет фото, собирает .mcaddon)
  generator_src.html + build_html.py — исходник и сборка веб-генератора
generator.html     — веб-генератор для телефона (собирается из tools/)
dist/PhotoLoader.mcaddon — готовый аддон с фото-образцом
```

## ⚙️ Технические детали

- Каждое фото — отдельная текстура полного разрешения и своя геометрия с точными пропорциями; выбор идёт через entity property `photo:id` и массивы рендер-контроллера, поэтому **одна сущность отображает любое фото** без дублирования.
- Масштаб и ориентация (стена/пол/потолок) — через анимацию костей по `photo:size` и `photo:face`: размер меняется без перезахода и без списка заранее заготовленных размеров.
- Обратная сторона фото отрисовывается с зеркальной UV-развёрткой, поэтому с обеих сторон изображение выглядит правильно.
- Сущность неуязвима, без гравитации и коллизии — фото нельзя случайно сломать или столкнуть; удаление только через меню.
- Версия паков автоматически поднимается при каждой сборке, чтобы Minecraft подхватывал обновление без чистки кэша.

## ⚠️ Ограничения

- Рекомендуемое качество — до 2048px по большей стороне (по умолчанию): большие текстуры могут не отображаться на слабых телефонах. На мощных устройствах можно 4096px.
- Практический предел — примерно 50–100 фото на пак (ограничение по памяти устройства, не аддона).
- Чтобы фото увидели другие игроки на сервере/в realms, пак с этими фото должен быть установлен в мир (гости скачают его автоматически при входе).
